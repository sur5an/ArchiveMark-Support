# ArchiveMark Support

Public support, troubleshooting, and privacy information for **ArchiveMark — Your Personal Media Archive**.

Visit the support site: <https://sur5an.github.io/ArchiveMark-Support/>

## Get support

Open a [support request](https://github.com/sur5an/ArchiveMark-Support/issues/new?template=support-request.md). Include your device model, operating-system version, ArchiveMark version, and the steps that led to the problem. Never post personal media or backup records.

## Privacy summary

ArchiveMark does not require an account and does not upload media to an ArchiveMark cloud service. It reads the libraries and folders selected by the user and writes copies and verification records to the selected backup destination.
